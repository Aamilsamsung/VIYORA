# VIYORA — Find your people

A responsive social universe prototype built with Vite, React and TypeScript. It features Orbit, Pulse, Spaces, Discover and Messages in a dark celestial visual style.

**This is a front-end-only demo.** People, activity and rooms are fictional sample data. Posts, follows, moods and direct messages are local browser data; there are no real accounts or live communications.

## Local setup

```sh
npm install
npm run dev
```

## Production roadmap

Connect authenticated user profiles, database row-level security, real-time messaging and reporting/blocking/moderation before public launch.
